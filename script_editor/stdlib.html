dofile

Compiles a squirrel script or loads a precompiled one and executes it.

path: Path to a script file.

raiseerror: If true, the compiler error handler is invoked in case of a syntax error.

returns: Value returned by the script or null if no value is returned.

loadfile

Compiles a squirrel script or loads a precompiled one and returns it as a function.

path: Path to a script file.

raiseerror: If true, the compiler error handler is invoked in case of a syntax error.

returns: Value returned by the script or null if no value is returned.
